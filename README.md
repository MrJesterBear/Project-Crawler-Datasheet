# Project Crawler - Datasheet
This is a datasheet for a project called Crawler.

As a VTT player, a lack of a proper character / party manager is frustrating and having to pay to use these is quite annoying.

In a world of open source technology and information, I find myself wanting to create my own attempt at this format.

While i am new to the world of development, this is definitely more a prototype and probably will be very ugly, but hey, it's something that will help me improve my ability.

# What is this?
This is simply just a datasheet providing some insights into my design philosophy as well as the technologies that are being utilised as well as any fun features of the code being written. After all, it is important that development is documented somehow for future understanding.

While I could have learnt new languages for this like react or GO, as it is my first non-university project I find that it is probably a good idea to stick to what I know even if it is not as efficient these frameworks.
