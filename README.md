# Project Crawler - Datasheet
This is a datasheet for a project called Crawler.

As a VTT player, a lack of a proper character / party manager is frustrating and having to pay to use these is quite annoying.

In a world of open soruce technology and information, I find myself wanting to create my own attempt at this format.

While i am new to the world of development, this is definitely more a prototype and probably will be very ugly, but hey, it's something that will help me improve my ability.
